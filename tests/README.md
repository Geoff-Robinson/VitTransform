# Issue repro tests

One folder per GitHub issue on this fork. Each folder holds:

- `in.clw` - a minimal Clarion source (ANSI, CRLF, no BOM) whose header
  comment explains the defect, the expected result and the buggy result
- `rules.txt` - the rule file that triggers it (only where the shipped
  `vitrules.txt` is not enough)
- `run.bat` - runs VitTransform from the repo root against the folder,
  writing the transformed file to `out\`
- `out\` - the transformed result of the last run (regenerated by run.bat)
